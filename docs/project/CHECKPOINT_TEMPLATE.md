# Progress and handoff checkpoint

Copy into a task/PR or a dated evidence record; do not overwrite this blank template.

- Task / F-ID / defect ID:
- Scope and intended user behaviour:
- Owner and reviewer (only if actually assigned):
- Base SHA, branch and resulting SHA:
- Files/interfaces/schema versions touched:
- Implemented behaviour:
- Verification commands and exact results:
- Evidence level (E0/E1/E2/E3/E4) and artifact links:
- Model/runtime/graph/weight provenance, if relevant:
- Actual resource/cost measurement, if performed:
- Failed cases and unresolved defects:
- Remaining acceptance / precise blocker:
- Merge/release state:
- Next concrete action and dependency:
- Docs/Linear snapshot updates made:

A checkpoint closes a milestone only when every required exit is met. A task count
or test count is not a project completion percentage. Never fill unknown values
with invented names, timing, cost or approval.
