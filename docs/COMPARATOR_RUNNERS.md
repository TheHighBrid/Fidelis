# Reproducible comparator runners and blind pairwise review (`F12` / `MEL-63`)

This runner pairs with [Benchmark corpus](BENCHMARK_CORPUS.md) (`F12-A`) to run
benchmark comparators cleanly without simulating missing accounts or blending
images into collages.

## Modules and CLI

- Module: [`fidelis/eval/comparators.py`](../fidelis/eval/comparators.py)
- CLI: [`scripts/run-comparators.py`](../scripts/run-comparators.py)
- Regression suite: [`tests/test_comparators.py`](../tests/test_comparators.py)

## Key invariants

1. **One full-resolution output per file.** Every comparator writes its own PNG
   into `<output-dir>/<split>/<case_id>/<comparator>.png`. Contact sheets and
   combined comparisons are forbidden.
2. **Missing comparator access is explicit.** Unconfigured comparators (`fidelis`,
   `vosr_challenger`, `pinned_clarity`, `dated_krea`, `selected_deterministic_base`)
   remain `"unavailable"` with zero fabricated metrics.
3. **Remote permission gating.** Remote comparators (`pinned_clarity`, `dated_krea`)
   are skipped (`"skipped_remote_disallowed"`) whenever `rights.remote_processing != "allowed"`.
4. **Honest metric semantics and dimension enforcement.** [`measure_pipeline_metrics`](../fidelis/eval/pipeline_metrics.py)
   records `source_consistency` vs `paired_ground_truth`, keeps `lpips: null`
   unless an actual implementation runs, and fails closed if any imported
   comparator's output size mismatches `target_dimensions`.
5. **Blind pairwise ballots and bootstrap CIs.** Randomized A/B ballots store
   truth keys separately, check category minimums (`>= 60%`), overall win
   (`>= 50%`) and preference+tie (`>= 80%`) rates, bootstrap 95% confidence
   intervals, zero critical defects, and label `n < 100` as preliminary.

## Usage

```bash
.venv/bin/python scripts/run-comparators.py run config/benchmark/inventory-v1.json \
  --allow-regression-manifest --output-dir /tmp/fidelis-reg-compare
```

Production acceptance runs omit `--allow-regression-manifest` and pass a verified
frozen 60-case lock generated by [`benchmark-corpus.py`](../scripts/benchmark-corpus.py).
